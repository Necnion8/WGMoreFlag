# WGMoreFlag
あると便利なWorldGuardのフラグを追加します

- `exit-via-teleport-myself`<br>
  領地外へテレポートするのを防ぎます<br>
  エンダーパールやコーラスフルーツ、スペクテイターのプレイヤー移動など
- `crafting` アイテムのクラフトを制御します (デフォルトで許可)

## 前提
- Bukkit
- WorldGuard (v7で確認)
